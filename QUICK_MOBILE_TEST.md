# 📱 Quick Guide - Test Tampilan Mobile SEKARANG!

## 🚀 Super Simple - 4 Langkah Saja!

Browser Edge sudah terbuka dengan website Anda. Sekarang:

---

### 1️⃣ BUKA DEVELOPER TOOLS
**Tekan keyboard:** `F12`

Atau klik kanan di halaman → pilih **"Inspect"** atau **"Periksa"**

**Hasilnya:** Panel baru muncul di bawah atau samping browser

---

### 2️⃣ AKTIFKAN DEVICE MODE (Mobile View)
**Tekan keyboard:** `Ctrl + Shift + M`

Atau klik icon **📱** (handphone) di pojok kiri atas DevTools

**Hasilnya:** Tampilan berubah jadi simulasi mobile!

---

### 3️⃣ PILIH DEVICE ANDROID
Di toolbar atas, ada dropdown **"Dimensions"**, klik dan pilih:

**Untuk Phone Android:**
- **"Samsung Galaxy S20 Ultra"** (412 x 915)
- **"Pixel 5"** (393 x 851)
- Atau ketik manual: **360 x 800**

**Untuk Tablet Android:**
- **"iPad Air"** (820 x 1180) - similar size
- Atau ketik manual: **768 x 1024**

**Hasilnya:** Website sekarang tampil seperti di Android!

---

### 4️⃣ TEST DASHBOARD
Login ke website (username: admin, password: [password Anda])

**Cek apakah:**
- ✅ Peringatan shift lebih kecil?
- ✅ Menu cards lebih compact?
- ✅ Hanya perlu scroll sedikit?
- ✅ Quick nav terlihat di navbar?
- ✅ Text masih readable?
