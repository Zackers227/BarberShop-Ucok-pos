# 🚀 Panduan Cepat - Print dari HP Android

## ⚡ Setup dalam 5 Menit

### 1️⃣ Siapkan Printer
```
✓ Charge printer sampai penuh
✓ Nyalakan printer
✓ Tekan tombol power 3-5 detik (masuk mode pairing)
✓ Lampu LED berkedip biru = siap di-pair
```

### 2️⃣ Hubungkan ke HP
```
✓ Buka Settings → Bluetooth di HP
✓ Scan device baru
✓ Pilih nama printer (contoh: "BlueTooth Printer", "RPP02")
✓ Masukkan PIN: 0000 atau 1234
✓ Status: Connected ✅
```

### 3️⃣ Akses Web App
```
✓ Buka Chrome di HP
✓ Ketik: https://barber-shop-ucok-pos.vercel.app
✓ Login (admin / admin123)
✓ Klik menu (⋮) → "Add to Home Screen" (biar seperti app)
```

### 4️⃣ Test Print
```
✓ Buka shift (jika belum)
✓ Buat transaksi test
✓ Klik "Detail Transaksi"
✓ Klik tombol "🖨️ Cetak"
✓ Pilih printer Bluetooth
✓ Set paper size: 58mm
✓ Klik Print
```

## ❌ Masalah Umum & Solusi

### Printer tidak terdeteksi
```
❌ Problem: Tidak ada printer di list
✅ Solusi:
   1. Pastikan lampu printer berkedip (mode pairing)
   2. Restart Bluetooth HP
   3. Unpair dan pair ulang
```

### Struk keluar tapi kosong
```
❌ Problem: Kertas keluar tapi tidak ada tulisan
✅ Solusi:
   1. Balik kertas (sisi thermal ke bawah)
   2. Ganti kertas thermal baru
   3. Cek kertas tidak expired
```

### Print terpotong
```
❌ Problem: Tulisan kepotong di samping
✅ Solusi:
   1. Set paper size ke 58mm (bukan 80mm)
   2. Set margin: None
   3. Pilih layout: Portrait
```

### Printer tidak connect otomatis
```
❌ Problem: Harus pair ulang tiap kali
✅ Solusi:
   1. Settings → Bluetooth
   2. Tap icon ⚙️ printer
   3. Centang "Auto-reconnect"
```

- [ ] Tutup shift

- [ ] Cek stok kertas cadangan (minimal 2 roll)
- [ ] Test print dari backup HP (jika ada)
