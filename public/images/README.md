## Cara Membuat Icons

Gunakan tools online seperti:
- https://realfavicongenerator.net/
- https://www.pwabuilder.com/
- Canva.com

Atau tools desktop:
- Adobe Photoshop
- GIMP (gratis)
- Inkscape (gratis)

## Design Rekomendasi

**Warna:**
- Primary: #3498db (biru)
- Background: #2C3E50 (dark blue)

**Icon Style:**
- Simple dan clean
- Gunakan simbol scissors (✂️) atau barber pole (💈)
- Jelas terlihat di berbagai ukuran

## Placeholder

Sementara waktu, gunakan icon default atau emoji 💈 sebagai placeholder.
